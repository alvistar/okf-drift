# {{PROJECT_NAME}} Knowledge Base

A knowledge base that describes no code: people and counterparts, things owned or run, open and closed matters, stable facts, recurring procedures and decisions. Tasks live in the task tracker, not here.

Find concepts with `okf search "<terms>" knowledge` (BM25, exact names and numbers); for a question in natural language, a hybrid index such as qmd finds the paraphrases BM25 misses. Each category index below lists its concepts with the same one-line description the concept carries.

- [Reference](/reference/index.md) — Stable facts that are needed often: identity, contacts that are not people, calendars, criteria.
- [Playbooks](/playbooks/index.md) — Recurring procedures. Check here before starting a task — if a playbook exists, follow it.
- [Decisions](/decisions/index.md) — One concept per decision, with status, date, reasoning and the alternatives rejected.
