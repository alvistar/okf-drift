# Coding Standards

This repository's coding standards live in its knowledge bundle, `knowledge/`. This file
holds no rule; it tells a code reviewer where the rules are. Review a diff against all
three sources below.

1. **Conventions.** Read in full each conventions index that exists:
   `knowledge/conventions/index.md` and `knowledge/project/conventions.md`. A convention
   governs a class of code, not only the files in its `code_refs`, so match it against
   the diff by its description. Apply every convention whose description matches the
   diff, and cite it by name in each finding.
2. **Concepts on the changed files.** For each changed file, run
   `okf search --for-path <file>`. Apply every pattern, decision and architecture concept
   it returns, and cite it by name.
3. **Rules not here.** A mechanical rule (formatting, a check a linter or type checker can
   make) belongs in lint, a hook or CI. A judgement rule the diff shows is missing is a
   finding: propose it, and record it in the bundle with `/okf-write`.

Generated by okf-drift. Change a standard in the bundle, never in this file.
